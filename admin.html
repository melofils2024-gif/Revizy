Publier une épreuve d'examen

Le sujet (l'épreuve) est gratuit : il attire les élèves. Le corrigé est payant : c'est lui qu'ils achètent. Le document n'est jamais exposé en direct — le serveur vérifie les droits puis le livre.

Le pays de l'épreuve (BJ, TG, CI, SN, GH…).
Cible une classe précise (3e, 1re, Tle…). Vide = toutes.
A, B, C, D, G… Vide = toutes.
Année de l'épreuve (liste de 2000 à aujourd'hui).
Matières du programme officiel du pays choisi.
Le PDF s'affiche dans l'onglet ; les autres formats se téléchargent.
Lien direct vers le PDF (source officielle) ou supabase:nom.pdf pour le bucket privé. Jamais de lien permanent vers un corrigé payant.
Le fichier part dans le stockage privé. Le serveur ne le sert qu'aux élèves qui ont les droits : le corrigé payant reste inaccessible sans paiement. 15 Mo maximum.
Obligatoire : n'intègre que des documents dont tu as le droit de les rediffuser.

La correction (obligatoire pour un corrigé payant)

C'est ce que l'élève achète : une solution rédigée, conforme au barème, relue par l'équipe. Un corrigé payant ne peut pas être mis en ligne tant que cette fiche est incomplète.

Écris la correction comme un prof : réponse, étapes, points, erreur fréquente. 80 caractères minimum (le serveur refuse une correction vide).
validation = la correction est juste, complète et conforme au barème.

Bon à savoir

  • Sujet gratuit : téléchargeable par tous, même sans compte.
  • Corrigé payant : le serveur refuse (402) tant que l'élève n'a pas payé.
  • Le déblocage est écrit par le serveur après validation FedaPay.
  • L'abonnement mensuel donne accès à tous les corrigés.
  • Formats acceptés : PDF, Word, OpenDocument, Excel, ZIP, images, TXT.
  • Classe et série permettent de ne proposer que les épreuves de l'élève.

Tu peux aussi importer un lot d'épreuves d'un coup avec node tools/import-epreuves.js epreuves/sources.json.
