Merci d'indiquer dans votre message :

  • l'adresse e-mail de votre compte (celle avec laquelle vous vous connectez) ;
  • si le problème concerne un paiement, la référence de transaction affichée par FedaPay ;
  • si le problème concerne un corrigé, le titre de l'épreuve (vous pouvez le signaler directement depuis l'épreuve, avec le bouton « Signaler »).

Formulaire

Un formulaire de contact en ligne est prévu : il enverra votre message directement au support, sans e-mail à installer de votre côté. Il n'est pas encore actif sur cette version du site — les messages envoyés au tuteur de l'espace élève ne sont pas pour autant perdus : ils sont visibles dans votre historique.

Questions fréquentes

Mon paiement n'a pas débloqué l'accès

Le déblocage est automatique et peut prendre quelques instants. Si rien ne se passe : vérifiez que vous êtes connecté avec le même compte que celui utilisé pour payer, puis contactez le support avec la référence de transaction.

J'ai payé mais je ne vois pas mon chapitre

Le contenu acheté apparaît dans votre espace, onglet « Épreuves » ou dans la matière correspondante. S'il manque, c'est généralement que le niveau, la classe ou la série de votre profil ne correspond pas au chapitre acheté : vérifiez ces trois informations dans votre profil.

Un corrigé semble faux

Utilisez le bouton « Signaler » affiché sur le corrigé : le signalement part directement dans l'espace d'administration et le corrigé est corrigé si besoin.

Je ne parviens pas à me connecter

Vérifiez l'adresse e-mail saisie. Si vous avez oublié le mot de passe, utilisez le lien de réinitialisation affiché sur l'écran de connexion.
